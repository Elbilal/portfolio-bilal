# Commandes du terminal

Chaque commande tapée dans le terminal est chargée depuis un fichier Markdown
de ce dossier. Les noms de commandes restent identiques dans toutes les
langues ; seuls les descriptions et le contenu sont traduits.

- about — qui je suis
- experience — où j'ai travaillé
- skills — mes compétences techniques
- projects — ce que j'ai construit
- education — où j'ai étudié
- contact — comment me joindre
- demo — bac à sable montrant chaque format pris en charge
